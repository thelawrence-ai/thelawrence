# Lawrence AI Studio

Act as a world-class UI/UX designer and front-end engineer. Create a high-end, visual portfolio website for "Lawrence" — an emerging UI/UX Designer and AI Developer specializing in modern generative tools, visual design, and agentic workflows.

1. DESIGN SYSTEM & TYPOGRAPHY:
- Visual Style: Cyber-minimalist, sleek, modern tech aesthetic. Ultra-smooth spring animations and smooth scrolling (Lenis style).
- Background: Deep slate/charcoal dark theme (#0B0F17) with glowing violet (#7C3AED) and cyan (#06B6D4) gradient mesh accents.
- Typography: Display typography pairing (e.g., Syne or Space Grotesk for headers; Inter or SF Pro for body UI). Glassmorphic card containers with subtle borders (border-white/10).

2. HEADER & NAVIGATION:
- Brand Logo: "Lawrence" (clean logo mark with a subtle neon glow).
- Floating sticky navigation bar with backdrop blur: [Work, Skills & Tools, UI/UX Concepts, About, Contact].
- Header Action: "Connect" button with glowing hover animation.

3. KEY SECTIONS:

- HERO SECTION:
  - Headline: "Designing the Next Era of AI-Driven Digital Experiences."
  - Subheadline: "Emerging UI/UX Designer & AI Technologist. Blending visual design precision with modern agentic workflows."
  - CTAs: "Explore Projects" (primary gradient glow) and "Contact Me" (glass outline).
  - Stat Badges: "Learning UI/UX" | "AI & Agent Workflows" | "Generative Design".

- SKILLS & AI STACK (Interactive Grid with Official Brand Logos/Icons):
  - Category 1: UI/UX & Visual Design (Figma, Framer, User Research, Design Systems, Prototyping).
  - Category 2: AI Models & Agents (Anthropic Claude, Manus AI, Google Antigravity, Lovable AI, ChatGPT).
  - Category 3: Creative & Code Tools (Midjourney, Flux, HTML/CSS, Tailwind CSS, Next.js).
  - Design note: Render each item as a glassmorphism pill/card with the tool's SVG icon/logo and hover scale effect.

- FEATURED WORK & UI CONCEPTS:
  - Project 1: "AI Agent Dashboard Concept" — Sleek UI mockup created using Figma & Lovable AI.
  - Project 2: "Generative Workflow Automation" — Agentic execution built using Claude & Antigravity.
  - Project 3: "Modern Landing Page UI" — Responsive, micro-interactive design built with Lovable AI.

- ABOUT LAWRENCE:
  - Two-column card: Left side features a personal highlight on learning AI-driven design; right side lists active focus areas (UI/UX Engineering, Prompt Architecture, Autonomous Agent Workflows).

- FOOTER & CONTACT (NO PHONE NUMBER):
  - Heading: "Let's Build Something Amazing Together"

  - Social Links Bar (with official brand icons):
    - Instagram: https://www.instagram.com/thelawrence.ai/

- 100% responsive layout across mobile, tablet, and desktop viewports.
